## Metadata header fields (per function `.c`/`.asm` header, or `decompiled.c`) (Inner)

```c

/*
* func-name: sub_401000 // Function name

* func-address: 0x401000 // Starting address

* export-type: decompile // decompile | disassembly-fallback

* callers: 0x402000, 0x403000 // Caller address (consolidated large files may be empty, see callgraph.txt)

* callees: 0x404000 // Callee address

* fallback-reason: ... // Only appears during fallback

*/
```

## Suggested Workflow Analysis

1. **Read first** `imports.txt` / `exports.txt` / `strings.txt` to establish a global view

2. **Find the entry point**: `exports.txt` / `callgraph.txt` (consolidated) or `function_index.txt` in the callers section 3. **Jump by Address**: After obtaining the target function `0x401000`, search for `func-address: 0x401000` in `decompiled.c`, or directly open `decompile/401000.c`.

4. **Tracing the Call Chain**: Use the addresses of `callers`/`callees` or `callgraph.txt` to trace the call chain.

5. **Large Files**: Prioritize using `function_list.txt` + `callgraph.txt` for indexing; do not feed the entire `decompiled.c` to the AI ​​at once.
